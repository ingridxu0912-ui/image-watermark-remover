# Image Watermark Remover

🖼️ 一款纯前端在线图片去水印工具，所有处理在本地浏览器完成，保护隐私。

## 功能特性

- 🚀 **快速便捷**：打开网页即用，无需下载安装
- 🔒 **隐私保护**：所有处理在本地浏览器完成，图片不上传服务器
- 🎨 **灵活标记**：支持矩形框选和画笔涂抹两种标记方式
- ✨ **精准去除**：只处理标记区域，保留原图其他内容完整
- 📥 **一键下载**：处理完成直接下载结果图片

## 技术栈

- Vanilla JavaScript - 原生 JS，轻量简洁
- Canvas API - 图片处理核心
- OpenCV.js - 图像修复算法
- Vite - 快速打包构建
- Tailwind CSS - 样式

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 使用方法

1. **上传图片**：点击或拖拽上传需要去水印的图片（支持 JPG/PNG/WebP）
2. **标记水印**：选择矩形框选或画笔涂抹，标记需要去除的水印区域
3. **开始处理**：点击「开始处理」按钮，等待算法完成
4. **下载结果**：处理完成后点击「下载图片」保存结果

## 部署

项目构建后输出静态文件到 `dist` 目录，可以部署到任何静态网站托管服务：

- Vercel
- Netlify 
- GitHub Pages
- 任意静态服务器
